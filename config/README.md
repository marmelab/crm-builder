# CRM Builder — Votre CRM sur mesure, sans coder

Bienvenue ! Ce système crée un **CRM personnalisé** adapté exactement
à votre activité. Pas besoin de savoir coder : vous décrivez votre
métier, une équipe d'agents IA s'occupe du reste.

## Ce que vous obtiendrez

- Un CRM web complet (contacts, entreprises, affaires, pipeline de vente...)
- Personnalisé avec **vos champs**, **vos étapes de vente**, **vos rôles d'équipe**
- Hébergé en ligne, accessible depuis n'importe quel navigateur
- Sécurisé avec des droits d'accès par rôle

## Comment ca se passe ?

### 1. La conversation de cadrage

Un chef de projet virtuel vous pose des questions simples sur votre activité :

- **Votre entreprise** — Quel secteur ? Combien de personnes dans l'équipe ?
- **Vos données** — Quelles informations suivez-vous ? (clients, produits, projets...)
- **Votre cycle de vente** — Quelles sont vos étapes ? (premier contact, devis, signé...)
- **Votre équipe** — Qui a accès à quoi ? (admin, commercial, lecture seule...)
- **Vos préférences** — Langue, thème clair/sombre, tableaux de bord souhaités

Pas besoin de tout savoir à l'avance : le chef de projet vous guide et propose
des choix par défaut que vous pouvez accepter ou modifier.

### 2. La validation

Avant de lancer quoi que ce soit, on vous présente un récapitulatif complet
de ce qui va être construit. Rien ne se passe tant que vous n'avez pas dit
**"C'est bon, on y va"**.

### 3. La construction automatique

L'équipe technique prend le relais en coulisses :
- Création de votre espace de code
- Mise en place de la base de données
- Développement des fonctionnalités
- Vérification du code et de la sécurité
- Tests de bon fonctionnement
- Mise en ligne

Vous recevrez des mises à jour à chaque étape importante.

### 4. La livraison

Vous obtenez :
- L'adresse web de votre CRM
- Les comptes d'accès
- Un guide de démarrage

## Ce dont vous aurez besoin

| Elément | Détail |
|---------|--------|
| Un compte GitHub | Pour héberger le code (gratuit) |
| Un compte Supabase | Pour la base de données (gratuit) |
| Un compte Vercel | Pour mettre en ligne (gratuit) |

Si vous n'avez pas encore ces comptes, le chef de projet vous guidera
pour les créer au bon moment.

## Pour commencer

Lancez simplement une conversation avec le système. Le chef de projet
prendra les choses en main et vous posera les bonnes questions.
