# CRM Builder Export

## Restore the CRM

```bash
cd sources
npm install
npm run dev
```

The `sources/` folder is a regular git repository — run `git log` inside it to browse history.

## Contents

- **sources/** — full CRM source code including `.git/` history.
- **sessions/** — chat session logs.
- **documentator/** — files generated by the documentator agent (if any).
