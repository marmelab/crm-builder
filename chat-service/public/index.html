      Configure deployment

      Paste the credentials of a Supabase project you created on supabase.com and a Cloudflare token to publish the app itself. Both are needed to deploy. Credentials stay inside the container; nothing is sent anywhere except Supabase and Cloudflare when you deploy.

      Open your project in Supabase Studio, then copy each value below.

      Project

      Find the project ref in Your Project → Project Settings. The Supabase URL is derived from it.

      API Keys

      Copy both keys from Your Project → Project Settings → API Keys.

      Function secrets

      Authentication

      The deploy automatically binds your live Cloudflare Worker URL as the Supabase authentication callback (site URL + redirect allow-list), so sign-in links redirect back to your deployed app — no manual Studio step. If that step can't complete, the deploy log will tell you to set it by hand.

      The app is built and published to Cloudflare Workers after the Supabase deploy.

      1. Open dash.cloudflare.com.
      2. Go to Manage account → Account API tokens → Create Token.
      3. Select Edit Cloudflare Workers from the Permissions Policies dropdown at the end of the header.
      4. Click Review Token, create it, then paste it below.
