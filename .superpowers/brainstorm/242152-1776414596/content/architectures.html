Option C — Claude Code SDK

Flux de données — Option C
🧑 Utilisateur
tape dans le chat
→
⚙️ Backend Node.js
@anthropic-ai/claude-code SDK
↓
Claude Code (SDK programmatique)
Même moteur que l'Option A (Claude Code), mais piloté via une API JavaScript
au lieu de pipes stdin/stdout.

const result = await claude.run("ajoute un champ Priorité", {
  cwd: "/app",
  onMessage: (msg) => streamToChat(msg)
})
📁 Fichiers CRM
+ hooks .claude/ existants
✓
les hooks / agents existants
continuent de fonctionner
Avantage vs A : pas de parsing de stdout, API propre
Risque : SDK encore jeune (~2025), peut changer, moins documenté que l'API Anthropic
